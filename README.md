### 👨‍💻 About Me

I'm a backend engineer who enjoys designing clean, secure, and scalable server-side systems. I care about the parts of a system that only show up under real use: database performance, concurrency, authentication, and access control.

- 🔭 Working on: system design and database optimization
- ⚙️ I care about: service-layer architecture, indexing and query tuning, rate limiting, JWT/RBAC security
- 💬 Ask me about: FastAPI, PostgreSQL, Redis, REST API design
- 📍 Based in Chennai, India
